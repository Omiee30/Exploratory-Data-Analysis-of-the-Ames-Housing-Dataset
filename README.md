# EDA Project: Exploratory Analysis of House Prices

## About the Project
This project focuses on Exploratory Data Analysis (EDA) of the Ames Housing Dataset. The main aim is to understand house prices and identify the factors that influence them using Python.

## Dataset
- **Dataset:** Ames Housing Dataset
- **Source:** Kaggle – House Prices: Advanced Regression Techniques
- **File:** `train.csv`
- **Records:** Approximately 1,460 rows and 81 columns

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Project Steps
1. Load and understand the dataset.
2. Identify numerical and categorical columns.
3. Calculate descriptive statistics such as mean, median, and mode.
4. Analyze data distributions using histograms and boxplots.
5. Study correlations between house prices and other features.
6. Create scatter plots and pair plots.
7. Generate a correlation heatmap.
8. Detect outliers using IQR and Z-score methods.
9. Check missing values, duplicates, and data quality.
10. Create a final dashboard and summarize the findings.

## Objective
The objective is to explore the dataset, understand the patterns in house prices, identify important features, and improve data quality.

## Conclusion
This project helps in understanding how different factors such as overall quality, living area, and neighborhood are related to house prices. It also provides practical experience with data cleaning, visualization, and statistical analysis.

**Note:** This project focuses only on EDA. No machine learning model is developed.
